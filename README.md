# Infooware Solutions Website

Responsive, single-file marketing site for Infooware's 15 product solutions.

- `index.html` — the complete site (HTML, CSS and JS inline; Google Fonts only external dependency)
- Home page: solution portfolio, pilot method, portfolio KPI chart, platform layers, regional entry pricing, partner program
- Per solution: a **Business case** page (`#/solutions/<slug>`) and a **Proof and diagrams** page (`#/solutions/<slug>/proof`)
- Contact page (`#/contact`) with a WhatsApp-composing enquiry form
- WhatsApp and call reach: +91 6359693055

## Hosting

Works on any static host. For GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

KPI figures are illustrative pilot targets, confirmed against each customer's own baseline.
